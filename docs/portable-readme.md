# DiskWeave 0.1.3 프리뷰

Windows 10/11 x64용 설치 없는 디스크 용량 분석 프로그램임.

- `DiskWeave.exe`를 더블클릭하면 GUI가 실행됨. 분석할 폴더를 선택한 뒤 스캔 시작을 누름.
- 진행 막대와 함께 확인한 파일·폴더 수 및 경과 시간을 표시함. 이미 분석한 드라이브의 하위 폴더만 새로 분석하려면 해당 경로를 지정하고 **새 최상위로 스캔**을 선택함. 새 스캔이 완료된 경우에만 겹치는 기존 분석을 교체함.
- 시작 시 분석 목록은 비어 있으며 C드라이브가 선택됨. 분석 목록은 자동 저장되지 않음.
- 화면·단축키 설정만 사용자 LocalAppData의 `DiskWeave/preferences.json`에 저장됨. ZIP 교체 시 설정이 유지됨.
- 일반 스캔과 열린 로컬 폴더의 목록 자동 갱신에는 관리자 권한이 필요하지 않음. 하위 폴더로 이동하면 해당 폴더의 바로 아래 목록을 확인함. 외부 변경에 대한 전체 검색과 용량 통계는 마지막 스캔 기준으로 표시함.
- 복사·이동·휴지통 등 파일 변경은 확인 후 수행됨. 원본 보존이 필요한 자료는 별도 백업이 필요함.
- 이 버전의 프로젝트 라이선스는 Apache 2.0이며 원문은 `LICENSE`, 저작권과 출처는 `NOTICE`에 포함함. 제3자 고지는 `THIRD_PARTY_NOTICES.md`와 `licenses/`에서 확인 가능함.
- 프리뷰 실행 파일은 서명되지 않았으며 Windows 11의 Smart App Control 정책에 따라 실행이 차단될 수 있음. 다른 Windows PC 실행은 미검증 상태임. [v0.1.3 릴리스 노트](https://github.com/ghminx/DiskWeave/releases/tag/v0.1.3) 참조.

## CLI

PowerShell에서 출력 파이프를 사용하면 같은 EXE의 CLI 출력과 완료를 확인할 수 있음.

```powershell
& .\DiskWeave.exe 'D:\분석할 폴더' | Out-Host
& .\DiskWeave.exe 'D:\분석할 폴더' --find '찾을 폴더' | Out-Host
& .\DiskWeave.exe 'D:\분석할 폴더' --at '하위 폴더' | Out-Host
```

GUI subsystem 실행 파일이므로 콘솔에서 파이프 없이 실행하면 터미널 종류에 따라 다음 프롬프트가 먼저 나타날 수 있음. 자동화에서는 프로세스 완료·종료 코드·표준 출력을 함께 확인해야 함.

## 주요 키보드 조작

- Ctrl+F / Ctrl+L: 검색 / 분석 대상 경로에 포커스를 둠.
- F5: 선택한 분석 위치를 다시 스캔함.
- Enter: 선택 폴더 내부 이동·파일 열기를 수행함.
- Ctrl+A: 표시된 목록 전체를 선택함.
- Ctrl+Shift+C: 선택 경로를 복사함.
- F2·Delete: 기존 이름 변경·휴지통 확인 창을 엶.

탐색 이력은 이번 실행 동안만 유지됨. 목록 위 검색칸에서 `현재 폴더 안에서`, `현재 스캔 위치 전체`, `스캔한 위치 모두`를 선택하고 검색어를 입력함. `다른 폴더 지정`과 `내 PC 전체`는 검색 버튼 또는 Enter로 시작하며 중앙 목록에 결과를 표시함. PC 전체 검색은 로컬 고정 드라이브를 대상으로 하며 이름 또는 경로와 요청한 유형이 맞는 결과를 최대 10,000건 표시함.

뒤로·앞으로·상위 이동은 화면 버튼으로 제공함. 우측 상단 설정에서 현재 폴더 자동 갱신, 스캔 동시 작업 수, 전역 검색 단축키, 백그라운드 실행을 변경할 수 있음. 전역 검색을 활성화하면 다른 앱에서도 Ctrl+Alt+Space로 작은 검색창을 호출할 수 있음. 작은 창은 ↑/↓로 결과 선택, Enter로 열기, Ctrl+Enter로 분석 화면 이동, Esc로 숨김을 지원함. 호출 조합은 변경 가능함.
