# 라이선스 원문 출처

- 레지스트리 패키지에 원문이 포함되지 않은 의존성의 고지 파일만 보관함. 프로그램 코드는 포함하지 않음.
- 출처는 `SOURCES.txt`의 공식 저장소·고정 커밋 URL을 기준으로 함.
- egui 계열은 레지스트리의 VCS 참조가 공식 저장소에서 조회되지 않아, 동일 버전 `0.37.0` 공식 릴리스 태그가 가리키는 공개 커밋의 라이선스를 사용함. 코드 동일성 검증을 의미하지 않음.
- 나머지 의존성의 라이선스는 설치된 Cargo 패키지 원문에서 패키징 시 복사함. Rust 표준 라이브러리·내장 글꼴·Pretendard 고지도 함께 포함함.
- 라이선스 포함 검사는 법률 검토나 프로젝트 공개 라이선스 선택을 대신하지 않음.
